# Job Application Tracker

A web application designed to help users organize and track job and internship applications. This project was built to practice core JavaScript concepts while creating a useful tool for managing the application process.

## Features

- Add job applications with company, position, and application status
- Edit the status of existing applications
- Delete applications
- Search through saved applications
- Filter applications by status
- Track the total number of applications
- Save application data using browser local storage so information remains after refreshing the page

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage
